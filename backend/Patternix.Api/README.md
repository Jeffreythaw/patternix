# Patternix API

ASP.NET Core backend for the Patternix solver.

## Run

```bash
dotnet run --project backend/Patternix.Api
```

## Endpoints

- `POST /api/datasets`
- `GET /api/datasets/{id}`
- `GET /api/datasets/{id}/rows`
- `POST /api/datasets/{id}/run`
- `POST /api/datasets/{id}/solve`
- `GET /api/theories`
