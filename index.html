Patternix
SQL-backed 4D pattern solver

Use the desktop or mobile HTML app on Vercel.

This repo can be deployed as static HTML on Vercel. The frontend talks to the C# backend over HTTP, stores datasets in SQL, and keeps parse, theory, and solve actions server-side.

Saved value is used by patternix-api.js. For Vercel, the backend must be public HTTPS. If you open the app with ?api=https://..., that value is saved automatically.
Open Desktop Full-width desktop layout with analysis, solver, and export panels. Open Mobile Touch-friendly layout optimized for phone screens and quick row entry.
